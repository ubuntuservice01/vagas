# TWENDE — Vamos juntos.
Fundação do monorepo. Passageiro e Motorista são aplicações independentes; Admin é web. Backend: projeto Supabase ovchyktojhrbydigwmzq.

Node 22+. Executar npm install na raiz, depois npm run dev:passenger, dev:driver ou dev:admin. npm run build compila as três interfaces. A raiz serve a pré-visualização das três interfaces via Vite.

Esta fase contém apenas interfaces iniciais; não implementa autenticação, corridas ou operações financeiras. Não publicar como serviço operacional. Capacitor, políticas RLS e integração funcional serão implementados e testados nas próximas etapas.
