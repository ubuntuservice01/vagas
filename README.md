# Ubuntu Service — Recrutamento

Landing page estática em HTML, CSS e JavaScript, sem dependências de compilação.

## Publicação
Em Settings > Pages, seleccionar Deploy from a branch, main e / (root), e guardar.

## Formulário
O formulário utiliza FormSubmit e envia para ubuntuservice71@gmail.com. Após a publicação, submeter uma candidatura de teste com dados fictícios, confirmar a activação no e-mail recebido e realizar um segundo teste. Confirmar a recepção dos campos e do PDF antes de divulgar. Não enviar dados reais durante a validação. O endereço de destino é visível no código público; após a activação, considerar substituir pelo identificador opaco fornecido pelo serviço.

## Identidade visual
O cabeçalho utiliza uma representação SVG aproximada do logótipo, não o ficheiro original.

## Privacidade
Validar as condições e práticas de tratamento de dados do fornecedor FormSubmit e definir retenção e acesso às candidaturas antes da abertura pública.
